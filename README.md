# Travel Planner — Web Sitesi

Travel Planner, seyahatleri tek yerden planlamak için geliştirilmiş bir .NET MAUI mobil uygulamasıdır. Bu depo, uygulamanın tanıtım sitesini içerir.

## Uygulama

- Gün gün plan ve sürükle-bırak sıralama
- Harita üzerinde yerler ve günün rotası
- Hava durumu ve akıllı bavul önerileri
- Bütçe, çoklu para birimi ve harcama analizi
- Arkadaşlarla harcama bölüşme
- Davet koduyla seyahat paylaşımı, cihazlar arası eşitleme
- Belgeler, yedekleme, karanlık tema; Türkçe ve İngilizce

Hesapsız kullanılabilir; reklam ve takip yoktur.

## Site

Statik HTML/CSS/JS. Tanıtım sayfası, Android APK indirme, gizlilik politikası, KVKK aydınlatma metni, kullanım koşulları ve hesap silme sayfalarını içerir.
